On The Bench Right Now

Ongoing projects

Undergrad and PhD work in active development, from FPGA stereo-vision cameras to an in-house RISC-V flight controller.

PRJ / DEPTH-CAM

Depth Camera on Reconfigurable Hardware

FPGA-accelerated stereo vision that replaces GPU-dependent depth sensors (~₹50,000 stock cost) with a low-power, customizable pipeline on a PYNQ‑Z2 board and dual USB webcams.

PYNQ Z2Stereo VisionFPGA Accel
Team · 2 UG
PRJ / OBJ-DEPTH

Embedded Real‑Time Object‑Level Depth Estimation

YOLOv8 segmentation plus Hungarian matching drives mask-based stereo disparity, delivering real-time per-object depth on a Raspberry Pi 5 — no GPU required.

YOLOv8Raspberry Pi 5Stereo Matching
Team · 2 UG
PRJ / FC-FPGA

Indigenous FPGA Flight Controller for UAV

A secure, domestically built flight controller on a Xilinx Basys3 board with a custom STM32 PCB, closing the import-dependency and data-sovereignty gaps in off-the-shelf UAV controllers.

Basys3STM32 PCBRF + IMU
In-house build
PRJ / FC-RISCV

RISC‑V Flight Controller — Alpana64v0

The same flight-control loop rebuilt around Alpana64v0, an in-house 64-bit floating-point RISC-V core (RV64 IMAFD), running live on an Arty A7 board.

RV64 IMAFDArty A7In-house core
Ongoing
PRJ / LIDAR-BEV

AI‑Accelerated LiDAR BEV Semantic Segmentation

A FINN-friendly quantized CNN turns raw LiDAR point clouds into real-time bird's-eye-view semantic maps for driving and robotics decisions, deployed on affordable Zynq/PYNQ boards.

FINNZynq / PYNQQuantized CNN
No GPU required
PRJ / ROBODOG

Robo Dog — Intelligent Quadruped Robot

An IMU-balanced, modular quadruped with dual manual (FlySky RC) and autonomous control modes, built for robotics competitions, inspection and research demos.

IMU ControlSTM32 + FPGAFlySky RC
